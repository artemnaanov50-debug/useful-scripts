# Useful Scripts

🚀 Полезные скрипты и утилиты для повседневной работы

## Что здесь есть

- **quick-backup.sh** — быстрый бэкап важных папок с датой
- **clean-node.sh** — очистка `node_modules` и кэша во всех проектах
- **port-kill.sh** — убить процесс на конкретном порту

## Как использовать

```bash
# Сделать скрипты исполняемыми
chmod +x *.sh

# Примеры
./quick-backup.sh ~/Documents ~/Projects
./port-kill.sh 3000
./clean-node.sh
```
